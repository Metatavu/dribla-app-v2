# dribla_app_v2

An upgraded version of the Dribla app with new features such as Keycloak integration, player profiles, in app purchases and statistics.

## Getting Started

You can mostly follow the same instructions as in the Honkalampi Messaging app as this uses many of the same tools.

- Install FVM (Flutter version manager), run flutter/dart commands with the fvm prefix
- Set up environment variables using Hashicorp Vault CLI (see Honkalampi instructions; make sure to run `./scripts/fvm-flutter-with-secrets.sh`)
- Set up .env file in the root folder with the required variable
- If modifying environment variables, update definitions in pubspec.yaml and then run `./scripts/dart-define-generate.sh`
- Generate new boilerplate for providers and classes annotated by Riverpod or freezed with `fvm dart run build_runner build --delete-conflicting-outputs`
- The Dribla API is generated with the OpenAPI generator and its spec is a git submodule in its own folder (dribla-api-spec)
- `git pull` in dribla-api-spec to pull new commit version for the spec
- Run `fvm dart run build_runner build --delete-conflicting-outputs` when there are changes to the api spec to generate a new version of the api
- Some dependencies are locked to specific versions due to conflicts when upgrading them, be mindful of that when updating
- New localizations can be edited in .arb files under `lib/l10n` and generated by running `fvm flutter gen-l10n` at the root of the project

## Developing in app purchases

- Utilizes the in_app_purchase package for managing purchases https://pub.dev/packages/in_app_purchase
- "dribla-store-testing.storekit" is currently included in the ios folder for testing purchases
- For IOS, you can follow the StoreKit instructions here https://developer.apple.com/documentation/xcode/setting-up-storekit-testing-in-xcode for setting up a development StoreKit to use for testing.
- On android, in app purchases will not work in a development environment at the moment

## Charts and statistics

- Charts utilize the fl_chart package: https://pub.dev/packages/fl_chart
